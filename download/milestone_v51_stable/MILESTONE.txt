 СОСТАВ ПОКАЗА (demo.smt)

   0.0 – 60.0 s   vignette (post, поверх)   (POST vig reads fbo0/fbo2 → screen)

 ПРОИЗВОДИТЕЛЬНОСТЬ ПО ИНТЕРВАЛАМ
   0–15 s   ~24 FPS   (nebula_raymarch raymarching — тяжелый)
  15–25 s   ~84 FPS   (sphere_scene + crossfade transition — лёгкие)
  25–35 s   ~67 FPS   (particle_swarm)
  35–60 s   ~55 FPS   (устоявшийся режим)

 АРХИТЕКТУРНЫЕ РЕШЕНИЯ v51
   1. Window:        WS_OVERLAPPEDWINDOW + WS_EX_APPWINDOW (видно в taskbar)
   2. Single-instance: CreateMutexA("Global\\DemoRT_v51_SingleInstance")
   3. SMT parser:    position-based prog (1-й=opacity, 2-й=progress) + backward
                     compat с явным "prog opacity ..."
   4. safeRun():     пустые программы не бросают exception, возвращают 0
   5. try/catch:     вокруг renderFrame в основном цикле — даёт читаемую ошибку
                     вместо std::terminate
   6. FBO pipeline:  RENDER→fboN, POST fboN→screen (не fboN→screen на чтение)
   7. Render loop:   PeekMessage + renderFrame + SwapBuffers, единый цикл

 КЛЮЧЕВЫЕ ФАЙЛЫ
   demo_runtime.cpp    8888 bytes   — WinMain + window + GL context + loop
   gl_executor.hpp    15827 bytes   — FBO pool, ShaderCache, executeOp, renderFrame
   sm_runtime.hpp     12913 bytes   — SMT parser, RPN, audio_vars, segment_at
   opengl_loader.h    10082 bytes   — GL 3.3 core function loader
   demo.smt             2310 bytes   — данные показа

 ИЗВЕСТНЫЕ НЕДОСТАТКИ (не блокирующие)
   • Shader'ы anxiety_mist, morph_grid, cozy_room_sdf, bloom, grain — написаны,
     но НЕ подключены к demo.smt. Готовы к использованию в v52.
   • vsync в windowed mode на Windows может не строго лимитировать до 60 FPS
     (видно по интервалу 15–25 s, FPS ~84).
   • Окно имеет рамку (не fullscreen). Для demoscene можно переключить на
     WS_POPUP позже, когда стабильность подтверждена.
