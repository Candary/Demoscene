# ТЗ: перевод генерации DOCX на Markdown + Pandoc

## Цель
Единственный источник контента — Markdown в `content/`. Документ собирается
одной командой. Version bump = правка поля `version` в `meta.yaml` + сборка.

## Контекст
- Старый генератор: `gen_sigil_btb_doc.py` (1099 строк, python-docx), 16 секций, v1.5.
- Эталон: `golden/v1.5.docx` — результат старого генератора (получи, запустив его).

## Правила
- Все команды выполняешь сам, пользователь ничего не вводит.
- Контент — только Markdown. Новый python-docx код не пишем.
- `gen_sigil_btb_doc.py` не изменять; после приёмки переместить в `legacy/`.
- `build.py` менять только по явной просьбе пользователя; после правки
  прогнать `tests/smoke.sh`.
- Версия живёт только в `meta.yaml`.

## Этапы (при провале проверки — дальше не идти)
0. Preflight: `pandoc --version`; `git init` + коммит; собрать v1.5 старым
   генератором → `golden/v1.5.docx`; `pandoc golden/v1.5.docx -t plain -o golden/v1.5.txt`.
1. Каркас: `content/`, `output/`, `meta.yaml` (title, version, lang: ru-RU),
   `build.py` (приложен), `reference.docx`. Для стилей: попробуй
   `--reference-doc=golden/v1.5.docx`; если стили не подхватились — дефолтный.
   Smoke: 3 тестовых файла `01_..03_` → сборка → удалить тестовые файлы.
2. Миграция: `pandoc golden/v1.5.docx -t markdown --wrap=none --extract-media=content/media`,
   разрезать по заголовкам H1 в `content/NN_<slug>.md` (NN — две цифры).
   Если заголовки в старом docx сделаны ручным форматированием, а не стилями
   Heading — roundtrip структуры не даст: конвертируй из исходника Python,
   секция за секцией. Пути картинок — относительно `content/`.
3. Приёмка: собрать v1.5 из Markdown; `pandoc output/*.docx -t plain` сравнить
   с `golden/v1.5.txt` (после нормализации пробелов); счётчики таблиц и картинок.
4. Коммит + тег `pandoc-migration`. Отчёт пользователю.

## Критерии приёмки
- Текст нового docx совпадает с эталоном (расхождения — только осознанные, списком).
- Число H1, таблиц и картинок совпадает с эталоном.
- `python3 build.py` с любого cwd даёт `output/sigil_btb_v<version>.docx`.
- Пользователю один раз нужно открыть docx и согласиться обновить поля (TOC).

## Стоп-условия (остановись и покажи ошибку + что пробовал)
- Одна и та же ошибка не решена за 3 попытки.
- Pandoc отсутствует и не устанавливается.
- Расхождение текста с эталоном нельзя объяснить форматированием.
