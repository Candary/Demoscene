# 6. meta.auto --- файл автоподстановки

Чтобы автотокены работали, их правила где-то должны быть записаны. Для этого служит файл meta.auto --- маленький конфигурационный файл рядом с журналом проекта. Я читаю его в начале каждого шага. Вот пример его содержимого:

> \# meta.auto --- автоподстановка для sigil-протокола (ведёт ассистент)
>
> \[v\] default=maxTask \# max номер задачи из roadmap.md
>
> \[md5\] default=latestZip \# отпечаток download/demo_intro_latest.zip
>
> \[md5:milestone\] = c0cbce51ba1b11f90cbfc474c0b2d70a \# замороженная v43
>
> \[status\] default=auto \# из журнала: последний подтверждённый
>
> \[env:mine\] = x64,GTX750,driver560.94,Win11 \# закреплено один раз
>
> \[trace\] default=auto \# прикреплён/отсутствует
>
> \[scope\] default=infer \# я вывожу из описания фичи
>
> \[avoid:default\] = opengl_loader.h, build_msvc.bat, build_mingw.bat \# НЕ трогать
>
> \[revert:default\] = lastgood \# последняя рабочая версия
>
> \[prio:default\] = optional
>
> \[after:default\] = run.contains(\"First frame rendered\") AND NOT run.contains(\"\[FATAL\]\") AND run.contains(\"\[Exit\] Main loop ended (code 0)\")
>
> \[status:levels\] = unverified → passed → confirmed \# A10: lastgood=only confirmed
>
> \[md5:canonical\] = chat-printed \# A6: md5 in #ack=checkpoint; sandbox-md5 сверяется с последним
>
> \[btb:source\] = btb_stats.json \# BTB v2: delta-only, shadow_mode, Laplace

Теперь meta.auto --- реальный файл в проекте (download/demo_intro/meta.auto). Рядом с ним живёт btb_stats.json --- состояние BTB (см. раздел 7). Оба переживают откат песочницы вместе с roadmap.md --- через zip и canonical-копию у вас.

Кто что пишет в этот файл:

  ---------------------------------------------------------------------------------------------------------------------------------------------------------------------
  **Строка в meta.auto**                              **Кто заполняет**                                                **Как часто меняется**
  --------------------------------------------------- ---------------------------------------------------------------- ------------------------------------------------
  \[env:mine\]                                        Вы говорите, я вписываю                                          Редко --- только при смене видеокарты/драйвера

  \[md5:milestone\]                                   Я, при заморозке новой контрольной точки                         При каждой заморозке

  \[avoid:default\]                                   Я, но substantive-правки --- только после вашего подтверждения   Когда вскрывается новый «хрупкий файл»

  \[v\]/\[md5\]/\[status\]/\[trace\] (default=\...)   Никто числом --- это правила, я разрешаю их на чтение            Никогда --- следуют за состоянием проекта
